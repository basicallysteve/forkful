# Mission

**Refresh statistics — grounded in Python — to be ready for an advanced applied Machine Learning course at university.**

## Why this matters (the reason behind the learning)

The user is about to start an **advanced, applied** Machine Learning course at
university. Applied ML quietly assumes a working fluency with the *probabilistic*
view of data: loss functions are expectations, models are estimators, evaluation
is inference, and regularization is a bias–variance trade-off. Without that
foundation, the course's practical work (scikit-learn, model selection, metrics)
feels like magic incantations instead of understood tools.

The goal is not to become a statistician. It is to **remove statistics as a
source of friction** so the ML course can be met with confidence.

## Learner profile (baseline, 2026-08-30)

- **Statistics:** solid on *descriptive* stats (mean, variance, distributions by
  name). Self-describes theory as shaky — **probability, inference, and
  hypothesis testing** are the growth areas.
- **Python:** comfortable with Python; uses numpy/pandas occasionally and can
  read code examples fluently.
- **Course:** advanced-level **Applied** Machine Learning, university. Syllabus
  not yet seen.

## Definition of success

The user can, without hesitation:
1. Read "E[·]", "Var(·)", "P(y | x)", "argmax", "μ̂/σ̂" and know what they mean.
2. Recognize the handful of distributions ML uses and when each appears.
3. Explain estimation (sample statistics as estimates; MLE) and why loss ≈ expected loss.
4. Reason about bias–variance, sampling, and basic inference well enough to
   interpret ML results and course material.
5. Translate any of the above into a short numpy/pandas snippet.

## Teaching approach

- Every lesson bridges **descriptive → probabilistic**, since that is the exact gap.
- Every concept is shown in **Python (numpy/scipy/pandas)** — the mission is applied.
- Ground each claim in trusted resources (see `RESOURCES.md`); cite them in lessons.
- Short lessons, one tangible win each, with retrieval-practice self-checks.
